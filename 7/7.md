# udocker
udocker commands are similar to Docker commands, but they are executed in a different way. Below is a table with the most common commands and their descriptions.

| Command          | Description                      | Example                         |
|------------------|----------------------------------|---------------------------------|
| `udocker pull`   | Transfer an image                | `udocker pull <tag>`            |
| `udocker create` | Create a container               | `udocker create <name>`         |
| `udocker run`    | Run a container                  | `udocker run <name>`            |
| `udocker ps`     | List running containers          | `udocker ps`                    |
| `udocker rm`     | Remove a container               | `udocker rm <name>`             |
| `udocker rmi`    | Remove an image                  | `udocker rmi <image>`           |
| `udocker exec`   | Execute a command in a container | `udocker exec <name> <command>` |
