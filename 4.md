# Overview of Module Management

| Command         | Description                  | Example                |
|-----------------|------------------------------|------------------------|
| `module avail`  | List available modules       | `module avail`         |
| `module load`   | Add a module                 | `module load <name>`   |
| `module list`   | List loaded modules          | `module list`          |
| `module unload` | Remove a module              | `module unload <name>` |
| `module purge`  | Remove all modules           | `module purge`         |
| `module show`   | Show module information      | `module show <name>`   |
| `module spider` | Show module dependencies     | `module spider <name>` |
